# Sleep Care by Country (public site)

Published write-up: https://health-culture-foundation.github.io/hcf-sleep-advice-site/

This repo holds only the public web page and the trimmed public `data.json`
(no ATC drug codes, no internal research notes). The research data, scripts and
notes live in the private repo `Health-Culture-Foundation/hcf-sleep-advice`
(`research/care-by-country`). Rebuild the page there and copy `index.html` and
`data.json` here to publish.

Draft research, not reviewed by a person, not medical advice.
